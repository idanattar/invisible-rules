# חוקים בלתי נראים · עידן עטר

סקיצות p5.js מבוססות Social Force Model.

## מבנה
- `index.html` – העמוד הראשי עם בחירת שלוש הצורות
- `sketches/jellyfish/` – מדוזה רדיאלית
- `sketches/jellyfish-down/` – מדוזה
- `sketches/tubes/` – טיובות הקשת

## העלאה ל־GitHub Pages
1. יוצרים repository חדש ב־GitHub (למשל `invisible-rules`), ציבורי.
2. Add file → Upload files, וגוררים את **כל התוכן** של התיקייה (לא את התיקייה עצמה), כך ש־`index.html` יהיה בשורש.
3. Settings → Pages → Source: Deploy from a branch → Branch: `main`, תיקייה `/ (root)` → Save.
4. אחרי דקה-שתיים האתר עולה בכתובת `https://<שם-המשתמש>.github.io/invisible-rules/`.
